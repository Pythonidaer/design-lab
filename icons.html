Sources, storage, and implementation

Johnny UI contains your 20 approved starter icons and is the default family. The other collections combine 24 common actions in Tabler Outline and Phosphor Regular, Bold, and Fill with additional arrow styles from Bootstrap Icons, Heroicons Solid, and Iconoir. These are candidates for comparison, not a mandatory project style. The starter files are stored with this site.

Additional MIT license notices: Bootstrap Icons · Heroicons · Iconoir.

Saved icons, settings, imports, and action assignments stay in this browser. Export a JSON collection for a portable backup, including SVGs and license notices. There is no account synchronization yet.

Stroke adjustment is available for Tabler Outline. Phosphor weights use different path shapes; choose Regular, Bold, or Fill instead. SVG imports accept basic vector geometry and reject scripts, styles, embedded images, and external references. Complex artwork may need simplification before importing.

Icons use one shared renderer and named action mappings. This adopts the centralization principle from Lea Verou’s article. It uses SVG rendering for this comparison tool, including editable Tabler strokes.
